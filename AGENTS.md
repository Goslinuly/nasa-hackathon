# Постоянное правило проекта Martian Map

Martian Map изучает и показывает **всю карту Марса**. Главный сценарий — пользователь сам выбирает любые координаты старта, цели и, при необходимости, промежуточные точки. Приложение строит и объясняет путь исследования по доступным данным для выбранного пользователем направления. Команда не ограничивает пользователя заранее выбранными популярными местами или подготовленными маршрутами.

Именованные объекты и демонстрационные маршруты служат примерами и точками поиска, а не границами продукта. Езеро, Гейл и другие районы с подробными снимками и DTM — локальные области для проверки детального режима, а не единственные доступные направления.

Для любого участка показывать, какие данные реально доступны: обзорная карта, подробный рельеф или недостаточное покрытие. Не представлять обзорный маршрут как подтверждённую проходимую тропу и не создавать видимость деталей там, где исходные данные их не содержат.

При планировании задач, документации, интерфейса и архитектуры сначала проверять соответствие этому глобальному пользовательскому сценарию. Если в предложении выбран один пилотный район, явно указывать, что это техническая проверка одного масштаба, а не изменение цели проекта.
