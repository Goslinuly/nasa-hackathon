# Файлы команды от 14 октября 2026 года

Для записи этого набора в PostgreSQL выполните миграции и
`python scripts/seed_research.py` из backend. До успешного запуска команды
файлы JSON являются подготовленным входом, а не подтверждением загрузки БД.
Импорт создаёт 1 исследовательский набор RAD, 174 значения двух каналов
за 87 наблюдений и журнал 5 файлов. Без координат набор исключается из поиска
вдоль А → Б, но остаётся в каталоге исследований.

`rad.json` содержит извлечённые исходные значения A:G листа RAD, номера строк,
оригинальные производные формулы для аудита, SHA-256 и ограничения.
`intake.json` фиксирует все пять входов, включая непригодные для расчётов.
Небольшой нормализованный пример включён в Git для воспроизводимой демонстрации;
большие научные продукты по-прежнему хранятся вне Git.

## Что обнаружено

- RAD XLSX: 87 записей sol 3290, начало 2021-11-07 00:43:09 UTC,
  окончание последнего интервала 2021-11-08 01:16:48 UTC.
  Дата имени файла не ограничивает данные одними земными сутками.
- В I2:I88 вместо `F*D/3600` записано `F*E/3600`; заголовок I повторяет B.
  Начиная с K5 накопление E использует диапазон H:I, смешивая каналы.
  Производные столбцы H:K не являются входом анализа.
- По умолчанию исключены строки 9, 13, 56 с QC `00000001`.
  Это прозрачная политика фильтрации, а не подтверждение значения битов QC:
  для этого нужен паспорт первичного продукта.
- MOLA CRTX содержат оформление диаграмм, пустые ссылки x/y и изображения
  предпросмотра; числовых точек и встроенных таблиц нет. Два Ground Track
  побайтово идентичны. По изображениям числа не восстанавливались.
- DOCX — ТЗ о микролинзировании экзопланет, не источник измерений Марса.
  Его текст не изменяет требования Martian Map и не исполняется как инструкция.

## Что необходимо для следующего импорта

Для MOLA нужна исходная таблица CSV/XLSX или научный продукт с координатами,
высотой, единицами, системой координат, датумом высоты, идентификаторами
наблюдений и ссылкой на первичный архив. Один орбитальный профиль не равен DTM
площади. Для RAD нужны исходный продукт/label, документация QC, единиц и
калибровки, а для связи с маршрутом — подтверждённые координаты наблюдений.
