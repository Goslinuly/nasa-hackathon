# Облёт участка

Симулятор свободного облёта участка HiRISE: модель в полном разрешении, настоящее марсианское небо со сменой дня и ночи, параметры времени и Солнца в кадре.

Это инструмент для осмотра и записи видео, а не часть сайта. Сайт показывает участок от первого лица — `frontend/src/features/walk/`.

## Запуск

Модель и карта высот лежат вне собранного фронтенда, поэтому страницу нужно открывать через локальный сервер, а не двойным щелчком: при открытии по `file://` браузер запретит загрузку `.glb`.

Из корня репозитория:

```
python -m http.server 8777
```

Затем открыть <http://localhost:8777/tools/flyover/>.

Модель 62 МБ, первая загрузка занимает несколько секунд.

## Участки

Переключаются кнопками в панели «Участок».

| Участок | Охват | Откуда рельеф |
|---|---|---|
| **Гейл** | 250 × 250 км, перепад 5,9 км | участок HiRISE 2 м внутри + обзорный рельеф кратера ~200 м/пикс вокруг |
| **Олимп** | 730 × 711 км, перепад 23,6 км | MOLA MEGDR, ~7,0 км/пикс |
| **Маринер** | 1644 × 830 км | MOLA MEGDR, ~7,3 км/пикс |
| **Эллада** | 1226 × 1423 км | MOLA MEGDR, ~5,5 км/пикс |

Гейл — единственный участок, где под ногами настоящий метровый рельеф; остальные три строятся в браузере из глобальной карты высот и показывают форму, а не детали. Уровень данных подписан в панели: зелёным — подробный рельеф, жёлтым — обзорный. Это и есть правило проекта: показывать, какие данные реально есть, и не делать вид, что деталей больше, чем в источнике.

Добавить свой участок — дописать запись в `SCENES` в начале скрипта: центр, половина окна по широте и долготе, подпись источника. Для `kind: 'mola'` больше ничего не нужно.

## Управление

| | |
|---|---|
| **Облёт** | левая кнопка — вращать, колесо — приближать, правая — сдвигать |
| **Полёт** | `F` или кнопка, затем щелчок — захват мыши. `W`/`A`/`S`/`D` — лететь, `Q`/`E` — вниз и вверх, `Shift` — вчетверо быстрее, колесо — скорость, `Esc` — выйти |
| **Время** | пауза, ×1, ×60, ×600, ×3600 или ползунок местного истинного солнечного времени |
| **τ** | оптическая толща пыли: меняет яркость у поверхности, цвет неба и дальность видимости |
| **Выдержка** | только экспозиция кадра, на расчёт не влияет |
| **Границы** | показать круг, за который камера не уходит |

Улететь нельзя: по горизонтали камера держится внутри круга радиусом полтора радиуса сцены, сверху есть потолок, снизу — отступ над рельефом. В режиме облёта точка, вокруг которой вращаемся, тоже не выходит за круг, иначе границу можно было бы обойти сдвигом. Расстояние до границы видно в панели «Камера».

В узком окне информационные панели сложены, чтобы не закрывать вид, — разворачиваются кнопкой «Панели».

## Откуда берутся числа

Формулы не продублированы «на глаз», а перенесены из проекта без изменений:

| Что | Источник |
|---|---|
| Время, сезон, положение Солнца | `frontend/src/features/sky/marsTime.ts` — Mars24 (Allison & McEwen) |
| Ориентация звёздного неба | `frontend/src/features/sky/marsSky.ts` — модель вращения IAU |
| Сумерки и видимость звёзд | `frontend/src/features/sky/skyMath.ts` |
| Шейдер купола неба | `frontend/src/features/sky/skyDome.ts` |
| Привязка участка, высоты | `frontend/public/data/local/gale-boxwork/manifest.json` |

Вывод каждой формулы — в [docs/PHYSICS.md](../../docs/PHYSICS.md).

Поток у поверхности считается по закону Бугера: `F = F_TOA · exp(−τ / sin h)`, воздушная масса в плоскопараллельном приближении. При высоте Солнца ниже 0,5° приближение не работает, поэтому воздушная масса не показывается.

Высота рельефа под камерой берётся из карты высот билинейной выборкой, а не лучом по модели: перебор 2,16 млн треугольников на каждый кадр останавливает отрисовку. Внутри участка HiRISE это DTM 2 м, снаружи — MOLA; какой источник сработал, написано в панели «Камера».

Цвет в сценах MOLA — гипсометрическая шкала по высоте, не снимок. Снимков такого разрешения на эти районы в репозитории нет, а раскрашивать рельеф «под Марс» без данных значит выдумывать детали.

## Чего здесь нет и почему

- **Вертикальное преувеличение.** Рельеф строго ×1, как и во всём проекте. Преувеличение сделало бы картинку эффектнее и неверной.
- **Заполнения дыр.** NoData остаётся дырой; над ней рельеф под камерой показывается прочерком.
- **Подсветки ночи.** У Марса нет Луны, способной осветить грунт, поэтому ночью виден только силуэт на фоне звёзд. Если открыть, когда на участке ночь, страница покажет утро и прямо об этом напишет.
