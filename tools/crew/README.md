# Экипаж: физиология выхода

Что происходит с человеком на поверхности: прыжок, суточный рацион, теплоотдача и расход воды на охлаждение, кислород по маршруту, доза радиации и советы по каждому из этих чисел.

## Где что лежит

| Файл | Роль |
|---|---|
| `frontend/src/shared/eva/crew.ts` | **источник истины**: все формулы, без React и без DOM |
| `frontend/src/features/crew/CrewPanel.tsx` | панель для сайта, только показывает то, что посчитал модуль |
| `frontend/src/features/crew/crew.css` | раскладка панели; цвета берутся из переменных оболочки |
| `tools/crew/index.html` | автономная страница: открывается без сборки, повторяет те же формулы |

Автономная страница нужна, пока на машине нет Node: посмотреть и показать результат можно сразу. Формулы в ней повторяют `crew.ts` один в один — **менять надо в обоих местах**.

## Запуск автономной страницы

Из корня репозитория:

```
python -m http.server 8777
```

## Встроить в сайт

```tsx
import { CrewPanel } from '@/features/crew/CrewPanel';

// сам по себе, со своими полями ввода
<CrewPanel />

// или с маршрутом из планировщика и небом из сцены прогулки
<CrewPanel legs={legs} skyViewFraction={sky} />
```

`legs` — массив `{ lengthM, slopeDeg }`. Если его передать, панель считает по нему, а не по своим полям; профиль планировщика превращается в такой массив парами соседних точек.

Можно обойтись и без панели — модуль чистый:

```ts
import { crewReport, DEFAULT_CREW } from '@/shared/eva/crew';

const report = crewReport({ ...DEFAULT_CREW, bodyKg: 62, loadKg: 45 });
report.jump.heightM;        // высота прыжка в скафандре, м
report.thermal.limiting;    // «вода» или «кислород»
report.advice;              // список советов с уровнями ok / warn / danger
```

## Что считается и на чём стоит

### Прыжок

Модель «та же работа ног». На Земле прыжок на высоту `h_E` требует работы `W = m·g_E·h_E`. Считаем, что на Марсе ноги способны на ту же работу, но поднимают уже массу со скафандром:

```
h_M = W / ((m + L)·g_M) = h_E · (g_E/g_M) · m/(m + L)
```

Без скафандра это ровно `h_E × 2,64`. **Вес влияет только через отношение `m/(m+L)`**: скафандр у всех одинаковый, поэтому тяжёлому человеку он мешает относительно меньше. Скорость приземления равна скорости отрыва — выше прыжок не значит мягче падение, просто дольше полёт.

Чего модель не учитывает: жёсткость скафандра, которая реально съедает часть работы. Настоящий прыжок будет ниже расчётного.

### Теплоотдача

Полезная механическая работа — только подъём центра масс, `P = m·g_M·V·sin θ`, и только вверх. Всё остальное от метаболической мощности становится теплом. Отводить его в разрежённой атмосфере нечем, поэтому тепло уносит сублиматор:

```
расход воды = тепло / 2,50 МДж/кг
```

2,50 МДж/кг — это сублимация льда 2,83 минус теплота замерзания 0,334: вода подаётся жидкой, замерзает и сублимирует. Проверка: при 350 Вт выходит 0,50 кг/ч, столько и расходовал ранец Apollo.

Панель сравнивает, на сколько часов хватит воды и на сколько кислорода, и говорит, что кончится первым. В проекте отдельно записано, что для пеших траверсов ограничивающим ресурсом обычно оказывается именно вода.

### Кислород по маршруту

Не считается заново: каждая нога проходит через `segmentCost` из `traverse.ts`, то есть ровно те же формулы, что и поиск пути на карте. Поэтому цифры в этой панели и в планировщике не могут разойтись.

Подъём дороже спуска, потому что в модели Санти за уклон отвечает слагаемое `0,35·V·G`, линейное по уклону.

### Питание

Основной обмен по Миффлину–Сан Жеору — земная формула, для Марса не валидирована. Расход на выходе берётся не из таблиц активности, а из той же метаболической модели: 1 Вт в течение часа — это 0,861 ккал. Белок 1,6 г/кг и жир 30 % калорийности — ориентир спортивного питания, не норма NASA.

### Радиация

Фон 0,64 ± 0,12 мЗв/сут — измерение RAD на Curiosity, диапазон 0,25–0,95 задаёт солнечный цикл. Экранирование рельефом:

```
доля = (1 − 0,21)·небо + 0,21
```

Пол в 21 % — вторичные частицы из грунта: они приходят снизу, и стена кратера их не закрывает. Карьерный предел 600 мЗв — эксплуатационное правило NASA, а не порог вреда.

## Проверка

Все числа сверены с независимым расчётом на тех же формулах. Для набора по умолчанию (женщина, 36 лет, 170 см, 70 кг, скафандр 45 кг, прыжок на Земле 40 см, маршрут 900 м +6° / 700 м 0° / 900 м −6°):

| Величина | Значение |
|---|---|
| прыжок в скафандре | 0,64 м |
| прыжок без скафандра | 1,05 м |
| время маршрута | 56 мин |
| кислород | 31,5 л |
| мощность | 126–208 Вт |
| вода сублиматора | 0,241 кг/ч |
| хватит воды / кислорода | 16,6 ч / 14,6 ч |
| рацион | 1910 ккал, Б 112 / Ж 64 / У 222 г |
| доза за выход | 0,020 мЗв |
| фон за 500 солов | 55 % карьерного предела |
